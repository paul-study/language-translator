## 1. Executive Summary

This document outlines the architecture and implementation plan for a JavaScript-based language translator feature. The feature supports two operational modes: **Single Device Mode** for live in-app translation and **Two-Device Chat Mode** for real-time translated conversations between users on separate devices. The system uses speech recognition for voice input, displays both original and translated text, and offers text-to-speech playback of translations.

## 5. Current Implementation (What's Built)

### 5.1 HTML Structure (index.html)

**Current Features:**
- Responsive container layout
- Two language dropdown selectors (12 languages each)
- Swap button (⇄) to switch source/target languages
- Input textarea for source text
- Output textarea for translated text (read-only)
- Translate button

**Supported Languages:**
| Language | Code | Language | Code |
|----------|------|----------|------|
| English | en | Russian | ru |
| Spanish | es | Chinese | zh |
| French | fr | Japanese | ja |
| German | de | Korean | ko |
| Italian | it | Arabic | ar |
| Portuguese | pt | Hindi | hi |

### 5.2 Styling (styles.css)

**Design System:**
- **Primary Colors:** Purple gradient (`#667eea` to `#764ba2`)
- **Background:** Gradient purple backdrop
- **Card Style:** White container with 20px border radius, drop shadow
- **Typography:** Segoe UI font family
- **Responsive:** Mobile breakpoint at 600px (stacks elements vertically)

**UI Components Styled:**
- Language select dropdowns
- Circular swap button (rotates 180° on hover)
- Text areas with focus states
- Gradient translate button with hover lift effect
- Disabled state styling

### 5.3 JavaScript Logic (script.js)

**Current Features:**
- DOM element references
- Swap functionality (swaps languages AND text content)
- Translation via MyMemory API (`https://api.mymemory.translated.net/get`)
- Loading state during translation
- Error handling with user-friendly messages
- Keyboard shortcut: Ctrl+Enter to translate

**API Integration Pattern:**
```javascript
// Current translation call structure
const response = await fetch(
    `https://api.mymemory.translated.net/get?q=${text}&langpair=${source}|${target}`
);
```

## 6. Planned Features (To Be Built)

### 6.1 Phase 1: Speech Services (Single Device Enhancement)

| Feature | Description | API Used |
|---------|-------------|----------|
| **Microphone Button** | Click to start voice input | SpeechRecognition |
| **Live Transcription** | Show text as user speaks | `interimResults: true` |
| **Speaker Button** | Play translated text aloud | SpeechSynthesis |
| **Language Mapping** | Map 2-letter codes to BCP 47 (en → en-US) | Custom mapping |

**Speech Recognition Configuration:**
```javascript
const recognition = new (window.SpeechRecognition || window.webkitSpeechRecognition)();
recognition.continuous = true;       // Keep listening
recognition.interimResults = true;   // Show partial results
recognition.lang = 'en-US';          // Source language
```

**Text-to-Speech Configuration:**
```javascript
const utterance = new SpeechSynthesisUtterance(translatedText);
utterance.lang = 'es-ES';   // Target language
utterance.rate = 1;         // Normal speed
speechSynthesis.speak(utterance);
```

### 6.2 Phase 2: Mode Selection UI

| Component | Description |
|-----------|-------------|
| **Mode Toggle** | Radio buttons or tabs: "Single Device" / "Two-Device Chat" |
| **Conditional UI** | Show/hide relevant interface based on mode |
| **Chat History** | Scrollable message container for chat mode |
| **Message Bubbles** | Styled bubbles showing original + translated text |

### 6.3 Phase 3: Two-Device Real-Time Chat

| Feature | Description |
|---------|-------------|
| **Room Generation** | Create unique 6-character room codes |
| **Room Joining** | Enter code or scan QR to join |
| **QR Code Display** | Generate QR code for easy mobile pairing |
| **Message Sync** | Real-time message broadcast via Firebase |
| **Connection Status** | Show connected/disconnected state |

**Message Data Structure:**
```javascript
{
    id: 'unique-message-id',
    sender: 'device-a-id',
    originalText: 'Hello, how are you?',
    originalLang: 'en',
    translatedText: '¿Hola, cómo estás?',
    targetLang: 'es',
    timestamp: 1704844800000
}
```

**Recommended Sync Technology: Firebase Realtime Database**
- No backend server required
- Free tier: 1GB storage, 10GB/month transfer
- Simple JavaScript SDK
- Automatic offline support

## 7. Browser Compatibility

### 7.1 Feature Support Matrix

| Feature | Chrome | Edge | Firefox | Safari | iOS Safari | Android |
|---------|--------|------|---------|--------|------------|---------|
| Core Translation | ✅ | ✅ | ✅ | ✅ | ✅ | ✅ |
| Speech Recognition | ✅ | ✅ | ❌ | ✅* | ✅* | ⚠️ |
| Speech Synthesis | ✅ | ✅ | ✅ | ✅ | ✅ | ✅ |
| Firebase Sync | ✅ | ✅ | ✅ | ✅ | ✅ | ✅ |

*Safari requires `webkit` prefix  
⚠️ Android Chrome doesn't support `continuous` mode

### 7.2 Known Limitations

1. **Firefox:** Speech Recognition is not supported. Users will see a warning and must use manual text input.
2. **HTTPS Required:** Speech Recognition requires secure context (HTTPS) in production.
3. **API Rate Limits:** MyMemory allows 1000 words/day for anonymous users.
4. **Mobile Continuous Mode:** Android doesn't support continuous listening; will use push-to-talk instead.

## 10. Technical Decisions & Rationale

| Decision | Choice | Rationale |
|----------|--------|-----------|
| **Translation API** | MyMemory | Free, no API key, already implemented |
| **Speech Recognition** | Web Speech API | Native browser support, no dependencies |
| **Text-to-Speech** | SpeechSynthesis API | Universal browser support |
| **Two-Device Sync** | Firebase Realtime DB | Serverless, free tier, simple SDK |
| **Styling Approach** | Vanilla CSS | No build step, simple maintenance |
| **No Framework** | Vanilla JS | Lightweight, portable, no dependencies |

## 11. Open Questions for Discussion

1. **Firefox Fallback:** Should we require Chrome/Edge/Safari, or build a robust manual input fallback?

2. **Translation Limits:** MyMemory has 1000 words/day limit. Should we add LibreTranslate as backup?

3. **Offline Mode:** Should we cache recent translations for offline use?

4. **Additional Languages:** Current: 12 languages. Should we expand the list?

5. **Authentication:** For two-device mode, should rooms be password-protected?
